# Ingestion

`chatdku-ingest` finds approved local documents, extracts their text, creates embeddings, and writes a persistent embedded Qdrant collection. It does not start or require a Qdrant server.

## Configure embeddings

Copy the example environment file before the first run:

```bash
cp .env.example .env
```

Choose exactly one embedding mode.

### Local Hugging Face model

The model downloads to `data/cache/models/` on first use and then runs locally.

```dotenv
CHATDKU_EMBEDDING_PROVIDER=local
CHATDKU_LOCAL_EMBEDDING_MODEL=intfloat/multilingual-e5-small
```

### Text Embeddings Inference

Use this mode when a TEI-compatible embedding endpoint is already running.

```dotenv
CHATDKU_EMBEDDING_PROVIDER=tei
CHATDKU_EMBEDDING_BASE_URL=http://localhost:18080
CHATDKU_TEI_EMBEDDING_MODEL=BAAI/bge-m3
```

Check the configured provider before ingesting:

```bash
uv run agent --check-embeddings
```

The health check sends one test string and prints the returned vector dimension. The harness raises a configuration error when neither a local model nor a fully configured TEI endpoint is available. This repository does not provide a TEI endpoint, API key, or embedding model files.

## Build an index

Put source files under `data/documents/` and run:

```bash
uv run chatdku-ingest
```

Or ingest a specific directory:

```bash
uv run chatdku-ingest path/to/documents
```

Supported extensions are `.pdf`, `.docx`, `.html`, `.htm`, `.json`, `.md`, and `.txt`. Hidden files and directories are skipped.

The command refuses to overwrite an existing collection. Rebuild it deliberately after changing source files, chunk settings, or embedding model:

```bash
uv run chatdku-ingest --replace path/to/documents
```

`--replace` deletes and recreates the local collection named by `CHATDKU_VECTOR_COLLECTION`; it never changes the source documents.

## Outputs

By default, ingestion writes:

| Path | Contents |
| --- | --- |
| `data/index/qdrant/` | Embedded Qdrant collection |
| `data/index/manifest.json` | Ingested source paths, hashes, sizes, and document count |

The manifest lets you review exactly which input files produced an index.

## Logs and troubleshooting

At `INFO` level ingestion reports the directory searched, files found, documents loaded, embedding-provider reachability, Qdrant location, and final manifest path. To list every discovered source file:

```bash
CHATDKU_LOG_LEVEL=DEBUG uv run chatdku-ingest path/to/documents
```

Embedded Qdrant may print this warning during index creation:

```text
Payload indexes have no effect in the local Qdrant.
```

It is expected. Payload indexes help server Qdrant filter large collections; they are not needed for this local harness.

If a PDF produces unreadable retrieval results, first verify the extracted text at ingestion time and then rebuild with `--replace`. A PDF generated by LaTeX usually works when it has a text layer. A scanned PDF needs OCR before it can be searched reliably.
